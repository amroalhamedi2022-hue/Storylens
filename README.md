# Lingua Tales 📚

Offline-first Android reading and vocabulary app for adults, with complete classic literature, contextual English/Arabic translations, book covers, old-world interior illustrations, responsive themes and touch-first reading. The repository remains Storylens for continuity; production Android package identity is **com.storylens.reader**.

**Latest binding user decision:** NO original AI-generated stories. Many genres of **long, complete, genuinely sourced vintage literature**, including complete Arabic originals of **كليلة ودمنة** and **ألف ليلة وليلة** with full, natural contextually written EN translations. Both are whole historic collections, not police novels and not disqualified merely for having internal fables. No children's adapted books, short-story filler or modern art. The cover itself must display the book title; meaningful period illustrations INSIDE each chapter. Retain fluid water-bubble taps/held presses, authentic sheet-curl reading, offline vocabulary, personalized glass themes and performance.
